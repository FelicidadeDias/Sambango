## Antes de publicar
Substitua as imagens de placeholder em /images pelos ficheiros reais:
hero-posto.jpg, fachada.jpg, galeria-01.jpg ... galeria-05.jpg e og-sambango.jpg.

Confirme com a direção:
- horário;
- serviços;
- especialidades;
- nomes dos profissionais;
- preços;
- seguradoras/convênios;
- email;
- posição exata no Google Maps.

O formulário abre o WhatsApp com os dados preenchidos.
